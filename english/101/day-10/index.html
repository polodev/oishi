✏️ ব্যাকরণ টিপ

this / that / these / those

  • this — কাছের একটি: this bottle
  • these — কাছের অনেকগুলো: these pills
  • that — দূরের একটি: that bottle
  • those — দূরের অনেকগুলো: those pills
শুরুবসবেউদাহরণ
thisকাছে, একটিThis bottle is small.
theseকাছে, একাধিকThese pills are small.
thoseদূরে, একাধিকThose books are old.
🧠 নিজে চেষ্টা করুন: (কাছের অনেক বড়ি) ___ pills are small.
This / These / That

উত্তর: These — কাছে + একাধিক = these।
