✏️ ব্যাকরণ টিপ

আবহাওয়া: It is … / It is raining

  • অবস্থা বোঝাতে: It is + adjective — It is hot. It is cool.
  • এখন হচ্ছে: It is + verb-ing — It is raining.
  • প্রশ্ন: How is the weather?
শুরুবসবেউদাহরণ
It ishotগরম
It israiningবৃষ্টি হচ্ছে
It isnot cloudyমেঘলা নয়

rain / is raining / rains
