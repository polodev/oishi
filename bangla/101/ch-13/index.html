এই গল্পের নায়িকা: ঐশী — মানে তুমি!Punctuation

ঐশী একটা বাক্য লিখল: "রাজ বলল ঐশী খাচ্ছে"।

মা বললেন, "কে খাচ্ছে? কে বলছে? চিহ্ন না থাকলে বোঝা যায় না।"

বাক্যের শেষে দাঁড়ি ( । ) বসে।

📖 গল্প ২/২

বিরামচিহ্ন: লেখার থামার চিহ্ন

থামতে হলে কমা ( , ) বসে।

প্রশ্ন করলে প্রশ্নচিহ্ন ( ? ), বিস্ময় বা আনন্দ হলে বিস্ময়চিহ্ন ( ! )।

কারও কথা হুবহু লিখলে উদ্ধৃতিচিহ্ন ( ' ' ) বসে।

প্রেসক্রিপশনে ডোজের জায়গায় একটা কমা বা দাঁড়ি ভুল হলে বিপদ — তাই হোমিওপ্যাথিক ডাক্তার প্রতিটা চিহ্ন যত্ন করে বসান।

💡 মূল কথা

চিহ্ন চেনা

  • দাঁড়ি ( । ) — বাক্য শেষ।
  • কমা ( , ) — অল্প থামা।
  • প্রশ্নচিহ্ন ( ? ) আর বিস্ময়চিহ্ন ( ! )।
  • উদ্ধৃতিচিহ্ন ( ' ' ) — কারও কথা হুবহু লেখা।
🏠 নিজে করে দেখো

চিহ্ন বসাই

  1. একটা অনুচ্ছেদ চিহ্ন ছাড়া লেখো।
  2. বন্ধুকে চিহ্ন বসাতে বলো।
  3. চিহ্ন না থাকলে কোথায় গুলিয়ে যায়, খুঁজে বের করো।
  4. নিজের একটা বাক্যে পাঁচটা ভিন্ন চিহ্ন ব্যবহার করো।
⚠️ আগুন, গরম পানি বা বিদ্যুৎ লাগলে বড়দের সাথে করবে।
